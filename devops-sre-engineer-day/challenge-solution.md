# Challenge solution: match a job ad to the lessons

**The fictional job ad** (an example, not a real company):

> **DevOps engineer, acme-app team**
> 1. Build and improve our CI/CD pipelines.
> 2. Automate the setup of our servers (infrastructure as code).
> 3. Use Git every day; review your colleagues' changes.
> 4. Run our app on cloud servers, in two regions.
> 5. Set up dashboards and alerts; take part in the on-call rotation.
> 6. Lead incident reviews and write clear runbooks.
> 7. Work closely with the developers.

**The match:**

| Line of the ad | Lesson |
|---|---|
| 1. CI/CD pipelines | Lesson 2, From Code to Users |
| 2. Automate server setup, infrastructure as code | Lesson 4, Automation |
| 3. Git, reviewing changes | Lesson 5, Version Control |
| 4. Cloud servers, regions | Lesson 3, Servers, Clouds and Data Centers |
| 5. Dashboards, alerts, on call | Lesson 6, Logs, Metrics and Alerts |
| 6. Incident reviews (postmortems), runbooks | Lesson 7, this lesson |
| 7. Work closely with the developers | Lesson 1, What DevOps Actually Means |

**The point:** every line of a real job ad is built from the ideas of this course. The tools change from
company to company; the ideas stay the same.
