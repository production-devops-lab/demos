# Lesson 8 challenge: match the words to the pictures

| Word | Picture | In the recipe-book comparison |
|---|---|---|
| **push** | your computer → GitHub: page 4 arrives in the library | taking your new pages to the library |
| **clone** | GitHub → a teammate's computer: the whole book, every page | copying the whole book at the library |
| **pull** | GitHub → your teammate: page 5 comes home | bringing home the pages others added |

One more check: what does a push send? Only **commits** (signed pages). Not the tray, and not changes
you have not committed yet.

The commands, for later: `git push`, `git clone <address of the repository>`, `git pull`.
