# Lesson 9 challenge: put the steps in order

Steps given: merge, open a pull request, push the branch, review.

**Answer:**

1. **push the branch**: your commits on `try-new-welcome` go to GitHub;
2. **open a pull request**: "please merge try-new-welcome into main";
3. **review**: a teammate reads the changed lines, comments, you fix with new commits, they approve;
4. **merge**: the branch's commits go into main.

Why this order: a pull request can only show commits that are already on GitHub (so push comes
first), and main only changes at the end, after someone else has looked at the change.
