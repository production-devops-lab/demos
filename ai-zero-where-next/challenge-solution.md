# Challenge: the five rules on one card

Write the five rules of the course on one card, in your own words, and keep it next to your screen.
Here is one example card.

```text
+--------------------------------------------------------------+
|  BEFORE I USE AN AI ANSWER                                   |
|                                                              |
|  1. Likely is not true. A calm tone is not a proof.          |
|  2. Nothing secret in the chat: no passwords, keys, tokens,  |
|     no data about real people, no internal names.            |
|     Replace with placeholders. Keep the error message.       |
|  3. Ask well: context, limits, one example,                  |
|     "tell me what you are not sure about".                   |
|  4. Review every line; deletes and stars twice.              |
|     Test in a copy, dry run first (echo), then LOOK.         |
|  5. Let it explain. Sort: explanation, guess, action.        |
|     Check one claim with a command that only reads.          |
|     The action is mine.                                      |
+--------------------------------------------------------------+
```

The loop behind the card: **ask well, review, test, decide**. The helper drafts; you stay the chef.
